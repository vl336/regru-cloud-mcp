# Contributing

Спасибо за интерес к проекту! Краткая шпаргалка, как предложить изменение.

## Нашли проблему?

Откройте [issue](https://github.com/vl336/regru-cloud-mcp/issues) и опишите:

- какой инструмент вызывали и с какими аргументами (аргументы — да, токены — нет);
- ожидаемое и фактическое поведение;
- текст ошибки (сообщения сервера безопасны для публикации).

## Предлагаете изменение?

1. Форк → ветка: `git checkout -b feature/<краткое-имя>`.
2. Изменения + `npm install && npm run build` (сборка обязана проходить; TypeScript strict).
3. Новый инструмент = запись в `src/tools.ts` + строка в таблице инструментов `README.md`.
4. Проверка на своём токене: `REGRU_CLOUD_TOKEN=<токен> npm run smoke` — токен остаётся только в вашем окружении.
5. Pull Request: что меняет и зачем, скрин/вывод проверки — приветствуется.

## Правила дизайна

- **Только read-only.** Сервер вызывает исключительно GET-эндпоинты CloudVPS API. Изменения, добавляющие мутирующие операции (создание/удаление/перезагрузка), не принимаются.
- **Без секретов в коде и истории.** Токены — только через переменные окружения; в коде/документации только плейсхолдеры.
- **Минимализм.** Без тяжёлых зависимостей; тонкий клиент, прозрачный проброс JSON-ответов API.
- **Человекочитаемые ошибки.** Сообщения об ошибках понятны агенту и не раскрывают токен.
